## Host on cPanel

```bash
git clone https://github.com/DrDeveshK/DoGalaxy.git ~/DoGalaxy
cd ~/DoGalaxy && ./bin/deploy.sh doswagat
```

Then activate the child theme in WP Admin. Full steps: [docs/DEPLOY.md](docs/DEPLOY.md).
